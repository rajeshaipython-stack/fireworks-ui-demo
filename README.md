# Fireworks Shop Demo — UI Preview

A generic, bilingual Tamil/English interface demonstration hosted as static files on GitHub Pages.

All products, prices, stock, invoices and analytics are fictional demo data. This is a design and software demonstration, not an operating shop or a commercial service. No online fireworks purchasing, payment or delivery is provided.

## Try the demo

Open the published website, choose **Shop admin**, then **Open interactive demo**. Changes are saved only in your current browser. There is no shared database or production administrator account on this static preview. Do not enter private customer or business information.

The full backend source is kept separately. This repository contains only the publicly served preview assets. Photography credits are included in the app; the hero is labelled AI-generated fictional festival artwork.
